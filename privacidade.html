Política de Privacidade

Esta política descreve o uso de dados pela ferramenta administrativa Portal Drone Backup, dedicada à cópia de segurança do sistema Porge. A ferramenta destina-se exclusivamente ao responsável autorizado.

1. Dados e permissões

Com consentimento do titular da conta Google, o aplicativo utiliza autorização OAuth para ler informações técnicas da pasta de backup, criar cópias e conferir os arquivos enviados. As permissões exatas são apresentadas pelo Google durante a autorização.

As cópias podem conter registros operacionais do Porge, incluindo informações de usuários, programação, aplicações agrícolas, insumos, estoque e cartografia. Esses dados não ficam disponíveis neste site.

2. Finalidade e processamento

Uma rotina autorizada, executada por GitHub Actions, obtém uma cópia do banco de dados, compacta, criptografa e envia o arquivo ao Google Drive. Em seguida, baixa a cópia para verificar a integridade e testar sua restauração isoladamente. Os arquivos não são usados para publicidade nem vendidos.

3. Armazenamento e segurança

Os arquivos são criptografados antes do envio. A chave de descriptografia não integra o backup nem este site. O controle de acesso aos arquivos depende das permissões concedidas pelo proprietário da conta Google Drive. Os provedores envolvidos incluem Google Drive, GitHub Actions e o serviço do banco de dados operacional.

4. Retenção e revogação

A rotina atual não exclui cópias automaticamente. Os arquivos permanecem armazenados enquanto o responsável os conservar e houver capacidade disponível. O titular pode excluir arquivos e revogar a autorização OAuth; a revogação impede novos acessos com essa autorização, mas não elimina cópias já existentes.

5. Esta página

Estas páginas são estáticas e não possuem cadastro, cookies próprios de publicidade, formulários ou scripts de análise. O serviço de hospedagem pode processar dados técnicos de acesso segundo suas políticas.

6. Contato

Para dúvidas sobre privacidade ou uso de dados nesta ferramenta, escreva para porgesuporte@gmail.com. A política poderá ser atualizada se mudarem o funcionamento da rotina, suas permissões ou prestadores.
